The project question

What becomes possible when the river model can differentiate?

The original formulation is linear when routing and decay parameters are prescribed. Estimating those parameters changes the operator itself—and makes the inverse nonlinear.

Important distinction

A complete routing kernel—not a complete MATLAB replacement.

The JAX package covers the computational core needed for differentiable inversion. The broader MATLAB research environment still owns real-data and basin-scale workflows.

  • In JAX: network validation, water/tracer routing, Muskingum dynamics, observations, objectives, parameter transforms, gradients.
  • Still in MATLAB: Amazon/Mackenzie/Mississippi studies, GLDAS/HYBAM/SWOT/nitrogen readers, complete Optimal Estimation scripts, plotting and preprocessing utilities.

Control, not field claim

B1 is deterministic and noise-free, with two runoff amplitudes, one shared K, and fixed X. Machine-precision recovery is a software and identifiability control—not an expectation for real rivers.
